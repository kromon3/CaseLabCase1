# Коллекция Postman

В каталоге лежат:

- `weather-digest.postman_collection.json` — коллекция (формат Collection v2.1) с обоими запросами
  цепочки, переменными, тестами и сохранёнными примерами ответов;
- `weather-digest.postman_environment.json` — необязательное окружение с теми же переменными
  (удобно, чтобы переключать город/число дней, не трогая коллекцию).

## Импорт

Postman → **Import** → перетащить оба файла. Затем выбрать окружение
«Weather Digest — Open-Meteo (local)» или пользоваться переменными коллекции.

## Запросы

| №   | Запрос                                        | URL                                                                                                                                                    |
| --- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Geocoding — координаты по названию города     | `GET {{geocodingBaseUrl}}/v1/search?name={{city}}&count=1&language=ru&format=json`                                                                     |
| 2   | Forecast — прогноз по координатам             | `GET {{forecastBaseUrl}}/v1/forecast?latitude={{lat}}&longitude={{lon}}&daily=temperature_2m_max,temperature_2m_min,precipitation_sum&forecast_days={{days}}&timezone=auto` |

Запросы связаны: тест-скрипт первого запроса читает `results[0].latitude/longitude` и записывает их
в переменные коллекции `lat` / `lon`, которые использует второй запрос. Поэтому коллекцию можно
прогнать целиком через **Collection Runner** — прогноз будет запрошен для города из `{{city}}`.

## Переменные

| Переменная         | Значение по умолчанию                  | Где используется          |
| ------------------ | -------------------------------------- | ------------------------- |
| `geocodingBaseUrl` | `https://geocoding-api.open-meteo.com` | запрос 1                  |
| `forecastBaseUrl`  | `https://api.open-meteo.com`           | запрос 2                  |
| `city`             | `Нижний Новгород`                      | запрос 1                  |
| `lat`              | `56.32867`                             | запрос 2 (заполняет тест) |
| `lon`              | `44.00205`                             | запрос 2 (заполняет тест) |
| `days`             | `3`                                    | запрос 2                  |

## Сохранённые примеры ответов

| Запрос    | Пример                                                  | Код |
| --------- | ------------------------------------------------------- | --- |
| Geocoding | город найден                                            | 200 |
| Geocoding | город не найден — тело без поля `results`               | 200 |
| Geocoding | некорректный параметр запроса (`count=abc`)             | 400 |
| Forecast  | прогноз на 3 дня                                        | 200 |
| Forecast  | `forecast_days=99` вне допустимого диапазона            | 400 |

Тела примеров — реальные ответы Open-Meteo. Обратите внимание: сценарий «город не найден»
у этого API — это **не** ошибка HTTP, а успешный ответ без результатов; утилита распознаёт его
отдельно (`NotFoundError`).

## Как обновить экспорт

Collection → `…` → **Export** → Collection v2.1 → сохранить JSON поверх файла в этом каталоге.
