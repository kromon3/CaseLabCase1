# Weather Digest — консольный «Погодный дайджест»

Утилита на Node.js принимает название города (или несколько городов), получает прогноз погоды
из открытого REST API [Open-Meteo](https://open-meteo.com/), выводит результат таблицей
в терминал и сохраняет отчёт в JSON-файл. Ключ доступа к API не нужен.

Данные собираются цепочкой из двух связанных запросов: сначала геокодинг
(название города → координаты), затем прогноз по этим координатам.

## Требования к окружению

- Node.js **20 или новее** (встроенный `fetch`, `AbortController`, флаг `--env-file`);
- npm 10+;
- сторонние HTTP-клиенты (axios и аналоги) не используются.

## Установка

```bash
git clone https://github.com/kromon3/CaseLabCase1.git
cd CaseLabCase1
npm install
cp .env.example .env
```

## Переменные окружения

Все настраиваемые параметры вынесены в окружение. Файл `.env` в репозиторий не попадает,
шаблон лежит в [`.env.example`](.env.example), значения читаются в [`src/config.js`](src/config.js).

## Запуск

```bash
node src/index.js --city "Нижний Новгород" --days 3
```

Полное описание параметров, пример вывода, таблица ошибок и структура проекта появятся
по мере реализации в ветках `feat/*`.

## Ветки и порядок работы

В `main` — только начальная инициализация репозитория. Каждая задача ведётся в отдельной ветке
и вливается в `main` через Pull Request после code review.

| Ветка                 | Зона ответственности                                               |
| --------------------- | ------------------------------------------------------------------ |
| `feat/cli`            | разбор и валидация аргументов, справка, форматирование вывода      |
| `feat/api-client`     | HTTP-клиент, запросы геокодинга и прогноза, параллельная обработка |
| `feat/report-cache`   | сохранение отчётов в JSON и кэш за текущую дату                    |
| `feat/error-handling` | единая обработка ошибок, коды завершения, документация ошибок      |
| `feat/bonus`          | Dockerfile, HTML-страница просмотра отчёта                         |
| `docs/readme-postman` | README, коллекция Postman                                          |

Сообщения коммитов — в стиле Conventional Commits: `feat`, `fix`, `refactor`, `docs`, `test`, `chore`.
